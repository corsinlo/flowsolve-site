# Flowsolve site

This repository contains a temporary, read-only preview of the Flowsolve
project website. Browse the preview in [English](/flowsolve-site/en/),
[Italian](/flowsolve-site/it/), or [Dutch](/flowsolve-site/nl/).

The static preview contains no forms, analytics, or tracking and collects no
data. It is a temporary project demonstration, not a transactional service.
